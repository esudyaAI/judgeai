## Правила для краулера (для T6)
- Уважать robots.txt каждого хоста; не обходить капчу и отказы.
- Честный User-Agent с контактом проекта; ≤ 1 запрос / 2 с на хост; экспоненциальная пауза при 429/5xx.
- Кешировать сырой HTML на диск (sha256), повторно не скачивать.
- Дедупликация по УИД дела (есть в 7 из 9 приватных образцов); у каждой карточки — url, дата загрузки, sha256 (правило 0 AUTORUN: происхождение данных).

## sudact.ru — детали (проверено 27.10; объём sitemap подсчитан 28.10, полный обход выполнен 28.10)
- **Sitemap:** `sitemap.xml` — индекс из 2 частей: `sitemap_part_0.xml.gz`, `sitemap_part_1.xml.gz`. Подсчёт (2 запроса): всего 96 776 URL, из них **33 698 `/regular/doc/`** (arbitral 37 064, magistrate 25 304, vsrf 710). Sitemap покрывает только свежее «окно» публикаций, не весь корпус. По случайной выборке 90 документов `/regular/doc/`: **Приговор ≈ 4,4%** (4/90; остальное — апелляционные определения/решения/постановления). Тексты приговоров на карточках полные (35–57 тыс. знаков), с УИД, формат «ПРИГОВОР Именем РФ… УСТАНОВИЛ… ПРИГОВОРИЛ» — совместим с RegexVerdictReader и дедупликацией по УИД.
- **Полный обход окна 28.10 (T6.1, краулер src/cli/sudact.py, честный UA, robots-гейт, адаптивный rate):** 33 698/33 698 URL, 0 отказов, 0 robots-блокировок, **1 159 приговоров** (~3,4% по всему окну; ранние секции доходили до 12%), дедуп по УИД/sha256, сырой кеш 110 МБ. Скорости: короткие пробы — до 14 rps (concurrency 8, все 200), продолжительная нагрузка мягко ограничивается сервером до ~5–7 rps без 429/5xx. Часть приговоров публикуется без УИД (как и в 7 из 9 приватных образцов) — дедуп по sha256 текста.
- **Поиск/фильтрация:** серверного поиска нет — результаты рендерятся только через `/regular/doc_ajax/` и `/vsrf/doc_ajax/`, оба **закрыты в robots** (проверено 28.10). Фильтр по статьям/типу акта возможен только по заголовку/тексту уже скачанной карточки.
- **Происхождение текстов** ([sudact.ru/about](https://sudact.ru/about/)): «использование информации только из достоверных источников – официальных сайтов судов РФ», акты включаются «в том виде, как они размещены в первоисточнике». Дедупликация по УИД обязательна.
- **Обезличивание:** для судов общей юрисдикции «из указанных актов исключаются персональные данные» кроме фамилий и инициалов участников.
- **Правила использования:** пользовательского соглашения на сайте не найдено (в подвале только «О проекте», «Политика в отношении обработки ПД» и «Все права защищены © 2012-2026»). Про API, массовую выгрузку и автоматический доступ сайт ничего не говорит.

## Юридические заметки (проверить юристом)
- Тексты судебных решений — официальные документы и не являются объектами авторского права (пп. 1 п. 6 ст. 1259 ГК РФ) — сверить с текстом ГК.
- Сайт-агрегатор может иметь право изготовителя базы данных (ст. 1333–1334 ГК РФ): извлечение «существенной части» базы без разрешения может быть нарушением. Поэтому: умеренный объём (сотни, не сотни тысяч), письмо проекту sudact с просьбой о разрешении/выгрузке (конкурс ВС — аргумент).
- Даже обезличенные тексты содержат фамилии — хранение = обработка ПДн (152-ФЗ). В precedent_case — только структурированные признаки и обезличенная фабула; сырые HTML — с ограниченным доступом.
