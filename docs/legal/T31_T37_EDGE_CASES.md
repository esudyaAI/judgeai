# Контракт граничных проверок T31–T37

Инженерный этап 29.10.2026; статусы и результаты — только в TASKS.md. Все правовые результаты остаются кандидатными (`needs_legal_review=True`), редакция на дату деяния и юридическая приёмка не заменяются тестами.

- Circumstance.quote additive: только положительный вывод суда даёт вход арифметике. Короткая цитата внутри отрицания не подтверждает факт. Пустой список модели не доказывает отсутствия отягчающих для62.
- Первая инстанция разбивается по лицам и их явно атрибутированным/общим сведениям; чередующиеся эпизоды возвращаются своему лицу. Коллективное признание без персональных назначений не даёт права угадывать сроки.
- CaseAnalysis.defendants хранит собственные проверки, наказание, обстоятельства, практику и warnings. Глобальные model legal_facts/рекомендации не используются для персональной арифметики. GET precedents требует defendant с нумерацией от1, если лиц несколько.
- Стадия читается по ст30 и словам «покушение на»/«приготовление к». В описании нужна однозначная привязка к одному эпизоду. Конфликт блокирует66/68 и шкалу рекомендации.
- Промежуточный69, вся неотбытая часть, присоединённая часть70 и цитаты сохраняются отдельно. Итог70 превышает новое наказание и всю неотбытую часть, не превышает их сумму; явно прочитанное присоединение сверяется арифметически. Максимум одного эпизода не заменяет промежуточный итог.
- Пересчёт71/72 использует точные отношения видов; штрафы/лишение права не переводятся в месяцы лишения свободы. Треть68 и предел62 вычисляются до выражения в днях/часах/рублях. Дробные сроки не обрезаются: существующий INTEGER cache остаётся NULL, точность сохраняется в JSON.
- Выбор69.2/69.3 учитывает категории всех эпизодов и неоконченные тяжкие/особо тяжкие. Поглощение по69.3 и превышение суммы не подтверждаются. Дополнительные наказания сопоставляются с ролью ADDITIONAL; их итог проверяется отдельно. Для лишения права вне санкции проверяется необходимость основания ч3ст47, а не объявляется безусловное нарушение.
- Для69.5 читаются только явные даты преступлений/прежнего приговора и зачёт. Одинаковая дата не доказывает очерёдность. Без состава прежних эпизодов полная арифметика69.5 остаётся непроверенной.
- Не охваченные комбинации видов, специальные пределы56, кратный/доходный штраф, неполные/противоречивые сведения требуют отдельной сверки. Массовый production refresh версии precedent-card/7 не подразумевается.
